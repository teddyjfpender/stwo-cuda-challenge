# Proof-v2 activation record

**Decision: public trial, unranked.** The challenge repository now exposes the proof-only CUDA, Metal, and CPU workflow, but no backend may publish a proof-v2 ranked score until all of the gates below are met. The old H200 command-time epoch is [archived](LEGACY_H200_V1.md) and does not supply proof-v2 baselines.

The [contract](../benchmark-proof-v2.json) pins nine identical public jobs and the same [input manifest](../fixtures/public-proof-v2.json) on each backend. The source pin `stwo-zig@1433d61b` contains the protected proof-call timers and is reachable from merged upstream PR [#213](https://github.com/teddyjfpender/stwo-zig/pull/213). The proposed score is a backend-specific, equally family-weighted geometric mean of paired Cairo, wrap, and fold proof-time ratios. Memory is an admission gate. Loading, preparation, full-command time, publication, and verification are diagnostics only.

| Gate | Current evidence | Remaining work |
| --- | --- | --- |
| Pinned source and timer ownership | PR #213 is merged; `setup-proof` and `capture-proof` attest backend-specific timer files and allowed source paths. | Freeze release builds and reject candidate changes that shift input-dependent proving outside the protected interval. |
| Public exact jobs | CPU and Metal each reproduced all nine current public proofs/roots on the M5 Max, and CUDA reproduced all nine on an H200 at the same source pin. The [M5 observations](../data/reports/m5-proof-v2-2026-10-03-full.tsv) and [H200 observations](../data/reports/h200-proof-v2-2026-10-03-full.tsv) retain proof-stage and command times separately. | Repeat as paired baseline/candidate trials on each ranking host. |
| Independent verification | Public direct runners check exact reference bytes. The H200 standalone PIE proofs passed the pinned official Rust Cairo verifier; the integrated CUDA pipeline verifies its resident Cairo leaves in process and does not serialize those leaf proofs. | Require independent verifier acceptance, including circuit roots, for every public and private case in the judge. |
| Trusted measurement | The direct runners split proof intervals from whole-command time and retain exact source/timer identities. The v2 scorer checks stage counts, paired rounds, and A/A dispersion. | Wire a sandboxed per-backend arm runner to the scorer. Authenticate each stage interval and build, sample capacity, run private holdouts, and sign the final receipt. Direct diagnostic JSON is not trusted rank evidence. |
| Host and capacity | The M5 Max is the designated CPU/Metal review host. An H200 direct preflight and all nine public jobs passed; the largest PIE used 134.1 GB measured peak device memory. | Freeze worker policy and memory-pressure admission for CPU and unified-memory Metal. Qualify a dedicated H200 judge with a pinned sandbox image and preflight. |
| Baselines and publication | The shared research TSV distinguishes modeled history, direct observations, and previous PR research. Metal PR #22 is promoted to the accepted editable frontier with its author-reported nine-case comparison recorded separately; it is unranked. | Record fresh paired proof-v2 baselines on each host, validate A/A noise, then enable signed scorecard publication and backend-specific site rankings. |

Participants can test now with `challenge.py setup-proof`, `benchmark-proof`, and `capture-proof`. A trial PR is reviewable, but a direct receipt or claimed speedup must not be promoted as a ranked improvement. Keep source commit, binary/timer digests, complete per-stage times, reference/verification results, command diagnostics, and capacity observations with each run.
